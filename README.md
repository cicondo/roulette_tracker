# Roulette Tracker

Mobile Web-App zur Erfassung von Roulette-Coups, Berechnung zweier Radsektoren und Protokollierung von Einsätzen und Ergebnissen.

## Nutzung

Die App läuft vollständig im Browser. Sitzungsdaten werden lokal im Browser gespeichert und können als JSON exportiert werden.

Für GitHub Pages unter **Settings → Pages** als Quelle **Deploy from a branch**, Branch **main** und Ordner **/(root)** auswählen.

> Hinweis: Roulette bleibt ein Glücksspiel mit negativem Erwartungswert. Die Auswertung vergangener Coups kann zukünftige Ergebnisse nicht zuverlässig vorhersagen.
